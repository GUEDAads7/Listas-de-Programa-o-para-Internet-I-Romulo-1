História da Internet e da Web

A Internet começou com redes de computadores que permitiam a troca de informações.

Linha do tempo

  1. 1960: Surgimento das primeiras redes.
  2. 1969: Criação da ARPANET.
  3. 1983: Adoção do TCP/IP.
  4. 1984: Criação do DNS.
  5. 1989: Proposta da World Wide Web.
  6. 1991: A Web se torna pública.
  7. 1990: Popularização dos navegadores.
  8. Atualidade: Surgimento de aplicações modernas.

Conceitos importantes

HTML
Estrutura o conteúdo das páginas.
HTTP
Permite a transferência de informações.
Navegador
Programa usado para acessar sites.
Servidor web
Fornece páginas e arquivos.
DNS
Converte nomes de sites em endereços IP.

Tim Berners-Lee criou a proposta da Web em 1989.

A Web 1.0 tinha páginas estáticas. Hoje existem páginas interativas.
