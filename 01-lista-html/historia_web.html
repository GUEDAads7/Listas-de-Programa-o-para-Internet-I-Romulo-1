História da Internet e da Web

A história da comunicação digital começou com redes de computadores que permitiam a troca de informações entre máquinas distantes.

Linha do tempo

  1. Década de 1960: surgimento das primeiras redes de computadores e desenvolvimento da ARPANET.
  2. 1969: primeiros nós da ARPANET entram em comunicação.
  3. 1983: adoção do TCP/IP, conjunto de protocolos que permite a comunicação entre redes.
  4. 1984: expansão do DNS, sistema que associa nomes de domínio a endereços IP.
  5. 1989: Tim Berners-Lee propõe a World Wide Web no CERN.
  6. 1991: a Web é disponibilizada publicamente; HTML e HTTP são utilizados para estruturar e transferir documentos.
  7. Década de 1990: navegadores gráficos popularizam a Web e servidores web disponibilizam páginas.
  8. Atualidade: aplicações Web modernas oferecem interação, atualização dinâmica e serviços complexos.

Conceitos importantes

HTML
Linguagem de marcação utilizada para estruturar o conteúdo das páginas.
HTTP
Protocolo utilizado na transferência de recursos entre cliente e servidor.
Navegador
Programa que solicita, interpreta e apresenta recursos da Web.
Servidor web
Sistema que recebe requisições e fornece páginas ou outros recursos.
DNS
Sistema que traduz nomes de domínio em endereços IP.

Tim Berners-Lee propôs a World Wide Web no CERN para facilitar o compartilhamento de informações.

Na Web 1.0, predominavam páginas estáticas e leitura de conteúdo. Nas aplicações Web modernas, usuários interagem, publicam dados e utilizam serviços dinâmicos.
