HTTP na prática: requisição e resposta

HTTP é o protocolo utilizado para transferir recursos na Web. O navegador atua como cliente: envia uma requisição ao servidor, que processa o pedido e devolve uma resposta.

Cliente, servidor, requisição e resposta

  • Cliente: normalmente o navegador que solicita um recurso.
  • Servidor: sistema que recebe a solicitação e fornece uma resposta.
  • Requisição: mensagem enviada pelo cliente.
  • Resposta: mensagem devolvida pelo servidor, com status e conteúdo opcional.

Métodos

GET: solicita a representação de um recurso, como uma página.

POST: envia dados ao servidor, por exemplo os dados de um formulário.

Exemplo de requisição HTTP

GET /index.html HTTP/1.1
Host: exemplo.com
Accept: text/html

Exemplo de resposta HTTP

HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8

<h1>Olá, mundo!</h1>

Códigos de status HTTP

  • 200 OK: a requisição foi processada com sucesso.
  • 301 Moved Permanently: o recurso foi movido permanentemente para outro endereço.
  • 302 Found: o recurso está temporariamente em outro endereço.
  • 400 Bad Request: a requisição contém erro ou não pode ser entendida.
  • 403 Forbidden: o servidor entendeu a requisição, mas não autoriza o acesso.
  • 404 Not Found: o recurso solicitado não foi encontrado.
  • 500 Internal Server Error: ocorreu um erro interno no servidor.
